# slawrensen.com

Static portfolio site for Stephen Lawrensen. Single page, no build step,
no dependencies. Product 01 is HWiNFO Sensors for Elgato Stream Deck;
product 02 is Checkmk Ops Deck, labeled as a private release candidate.
HWiNFO's Windows-only requirements remain specific to that product.

## Structure

```
public/
  index.html    the whole site — self-contained (inline CSS + dependency-free vanilla JS)
  _headers      Cloudflare Pages security + cache headers
  favicon.svg   brand mark
  robots.txt
  404.html      styled 404 page
  assets/       product screenshot (webp), device photo (webp), social card (jpg)
.github/workflows/pages-deployment.yaml   CI/CD
```

## Deploy

Push to `main`; GitHub Actions deploys `public/` to Cloudflare Pages via
`cloudflare/wrangler-action`. Live at <https://slawrensen.com> — `www` 301s to
the apex, and it is also served at <https://slawrensen.pages.dev>.

Manual deploy:

```
npx wrangler pages deploy public --project-name=slawrensen
```

## Local preview

```
python -m http.server 8791 --directory public
```

then open <http://localhost:8791/>.

## Editing

It is one HTML file. Design tokens (colour, spacing, type scale) live in the
`:root` CSS variables at the top. Add a product by copying the `.product`
block and updating the product count.

Checkmk's image is generated by its renderer from sanitized demo fixtures,
not a hardware photograph. Refresh `public/assets/checkmk-ops-deck-demo.png`
from the approved Ops Deck source when the renderer changes. Keep the
candidate status and private-source disclosure until the same package has
passed both native platform gates. Add public documentation/download links
only after their destinations are deployed and verified; the intended docs
location is `https://docs.slawrensen.com/checkmk-ops-deck/`.

Candidate portfolio work stays on its scoped branch. A push to `main`
deploys automatically, so local preview or a draft PR is not authorization
to merge or deploy it.
