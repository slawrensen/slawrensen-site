Temperatures, fans and power, live on your Stream Deck.

My Stream Deck + XL running HWiNFO Sensors, 25 July 2026.

I build two Stream Deck plugins. Mac Sensors reads your Mac. HWiNFO Sensors reads Windows through HWiNFO. Both are free and open source, with no ads and no telemetry.

macOS · 1.0.1

Mac Sensors

Temperatures, fan speeds, power, CPU activity, memory, storage and network from your Mac, on keys and Stream Deck + dials. It only reads: no fan control, no administrator password, no helper app.

macOS 13.5 or later · Stream Deck 7.1 or later · Apple silicon and Intel

Get it on the Marketplace Docs Source
Windows · 1.7.1

HWiNFO Sensors

CPU and GPU temperatures, clock speeds, fan speeds, usage and power from HWiNFO, on the same keys and dials. HWiNFO is a separate free program; turn on its Shared Memory Support.

Windows 10 or later, x64 · Stream Deck 6.9 or later · HWiNFO

Get it on the Marketplace Docs Source

No ads, no telemetry. Neither plugin makes a network request; the only connection is to the Stream Deck app on your computer.

Read-only, open source. They never change a hardware setting. The code is MIT licensed, and questions go to GitHub Issues for Mac Sensors or HWiNFO Sensors.
