Stream Deck plugins for Mac and Windows.

I build them on my own. Each one puts your computer's temperatures, fan speeds, power and load on Stream Deck keys and dials. Both are free and open source, with no ads and no telemetry.

macOS · version 1.0.1

Mac Sensors

Temperatures, fan speeds, power, CPU activity, memory, storage and network from your Mac. One to four readings on a key, a sparkline, bar or ring, and amber and red alerts. It only reads: no fan control, no administrator password, no helper app.

macOS 13.5 or laterStream Deck 7.1 or laterApple silicon and Intel

Windows · version 1.7.1

HWiNFO Sensors

CPU and GPU temperatures, clock speeds, fan speeds, usage and power from HWiNFO, on the same kinds of keys and dials. HWiNFO is a separate free program; turn on its Shared Memory Support and the plugin reads from it.

Windows 10 or later, x64Stream Deck 6.9 or laterHWiNFO

How I build them

  • No ads, no telemetry. Neither plugin makes a network request. Their only connection is to the Stream Deck app on your computer.
  • Read-only. They read sensors and never change a hardware setting.
  • Open source. MIT licensed. Read the code, or build it yourself.
  • Questions and bugs go to GitHub Issues for Mac Sensors or HWiNFO Sensors.
