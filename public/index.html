HWiNFO Sensors for Elgato Stream Deck

Software for people who care how their machines run.

Built by Stephen Lawrensen

HWiNFO Sensors puts live readings from HWiNFO on your Stream Deck: temperatures, clock speeds, fan RPM, usage and power, on Stream Deck keys and on the dials of the Stream Deck + and + XL. Free and open source.

Get it on the Elgato Marketplace Setup guide

Windows 10 or later, x64 · Stream Deck app 6.9 or later · HWiNFO, free or Pro

One instrument, shown the way you will use it.

Every key and dial face on this page is real output from the plugin's own renderer, taken from its documentation. The readings are fixed example values; this page does not read your machine.

How much fits on one key

A key shows one reading with a sparkline, bar or ring, or stacks two, three or four. Compare how legible each stays: the small copy is roughly the size of a real key on a desktop monitor.

Show a key holding

Example values, rendered by the plugin.

Seven themes, one alert language

Themes apply per key or to the whole deck. Paper is a high-contrast light theme for bright rooms and low vision. Set a warn and a critical value: past either one, the whole key turns amber or red, in the same two colours on every theme, so an alert is carried by the whole field changing, not by hue alone.

It says when it cannot read

If HWiNFO stops publishing, a key does not keep showing its last number. Frozen values become a "Not updating" screen after 15 seconds, and every other failure has its own screen that names the fix. All status screens

Dials on the Stream Deck + and + XL

Rotate to step through readings, push to reset the session min and max, touch to cycle the stat. A dial can also list its rotation set as two or three rows, and an HWiNFO Control key can drive dials from anywhere on the deck.

Install

  1. Install the plugin from the Elgato Marketplace, or double-click the .streamDeckPlugin file from GitHub Releases.
  2. Run HWiNFO and tick Shared Memory Support in its settings. Run HWiNFO and the Stream Deck app at the same privilege level: both elevated or both normal.
  3. Drag Sensor Reading onto a key and pick a sensor from the list. The key goes live.

Free HWiNFO turns Shared Memory off after 12 hours. With Gadget reporting enabled, the plugin falls back to it and switches back by itself. HWiNFO is a separate program by REALiX; the plugin does not bundle it.

How it is made, with the evidence.

Four habits from HWiNFO Sensors, each next to the place you can check it.

Say exactly how sure I am

Hardware support is published at four levels: physically verified, simulated against the SDK, verified by a user, or expected to work with stated limits. One device is claimed as physically verified, because one device was tested in hand.

Compatibility matrix

Show the failure, not a stale number

Every failure state has its own screen that names the cause and the fix, so a frozen value does not sit on a key as if it were live: after 15 seconds without an update, the key says so.

Status screens

Measure, and say how

One shared-memory poll of 548 live readings, copied and decoded, takes 8.5 µs on average over 1,000 runs on my machine. The performance log names the harness behind each figure.
